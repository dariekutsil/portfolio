# Daria — Portfolio

Responsive portfolio made with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — bilingual EN/RU project descriptions, project navigation, filters
- `assets/` — bundled imagery (18 stills + 2 GIFs)

## Hosting on GitHub Pages
Go to **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. Your site should publish at `https://dariekutsil.github.io/portfolio/` once GitHub Pages finishes deployment.

## Before using for job applications
Review the project copy against your original project descriptions and contributions. Add your verified contact details and CV in `index.html`. The text is editorial copy based on the available visual materials, not a verified transcription of the screenshot.

All imagery is stored locally in `assets/`; no Drive embedding is required.
